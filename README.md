# simple-Woocommerce-mail--excel-plugin
simple plugin you can use with woocommerce. This plugin sends you order information to excel.

Deploy the Apps Script as a Web App

1. Click Deploy → New deployment

2. Select Web app

3. Execute as: Me

4. Who has access: Anyone

5. Deploy → copy the URL

Your final webhook URL should be:
https://script.google.com/macros/s/XXXXX/exec?token=YOUR_TOKEN
